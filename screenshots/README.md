# Screenshots

This directory is designated for terminal recordings, output captures, and demonstration screenshots of the Website Uptime Checker CLI.

## Recommended Screenshots to Add

- **CLI Help**: `python src/uptime_checker.py --help`
- **Single URL Check**: `python src/uptime_checker.py --url https://example.com`
- **Batch Check**: `python src/uptime_checker.py --file demo_data/websites.txt`
- **JSON / CSV Export**: Generating reports in `reports/`
- **Quiet Mode**: `python src/uptime_checker.py --url https://example.com --quiet`
- **Automated Unit Tests**: `python -m unittest discover -s tests -v` (all tests passing)
